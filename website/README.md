# MemeMind AI

A standalone, single-page web app: an AI agent that paper-trades a basket of
**fictional** meme coins, starting from a simulated **$1,000** balance, with
one objective — grow that balance as much as possible. It is completely
separate from the `memebot` Python trading bot elsewhere in this repository
— different stack, different (fictional) market, no shared code or data.

**100% simulated, entirely in your browser.** There is no backend, no real
exchange, no real wallet, and no real money anywhere in this app. Coin
names, prices, and volume are generated by an in-browser market model.
Nothing here is investment advice. See the disclaimer in the page footer.

## What's actually running

- **A simulated market** (`src/lib/market.ts`) — ten fictional meme coins,
  each following a regime-switching random walk (choppy / uptrend /
  downtrend / pump / dump) with occasional fat-tail jumps, so price action
  feels like a volatile meme coin market without being tied to any real
  token or exchange feed.
- **A real online-learning trading agent** (`src/lib/agent.ts`,
  `src/lib/simulation.ts`) — not a scripted demo. Two linear policies
  (entry and exit) score each coin from a handful of technical features
  (momentum at three horizons, volatility, RSI, distance from its moving
  average, volume surge, and — for exits — the position's own unrealized
  P&L). They start from a simple momentum/mean-reversion prior and are
  updated after **every closed trade** with a gradient-bandit-style rule:
  weights move toward the features that were present before a profitable
  trade and away from the features present before a loss. Exploration and
  the learning rate both decay as the model accumulates trades, so it
  leans increasingly on what it has learned rather than trading at random.
  Position size scales with the model's confidence and experience, so
  early, uncertain trades risk less of the balance than later, better-
  informed ones.
- **Hard risk controls independent of the learned policy** — a per-trade
  stop-loss, a max concurrent position cap, and a max hold time — so a bad
  stretch of learning can't wipe the account in one trade.
- **A live dashboard** — equity curve, per-coin sparklines, a "brain" panel
  visualizing which features the model currently weighs most heavily, and
  a running feed of every trade with a plain-English reason.

Progress (the portfolio, trade history, and the AI's learned weights)
persists to `localStorage`, so it picks up where it left off on reload.
The header's **Reset** menu offers a fresh $1,000 portfolio that keeps
the AI's learned brain, or a full reset that wipes both.

## Run it

```bash
cd website
npm install
npm run dev       # dev server with hot reload
npm run build     # type-checks and produces dist/
npm run preview   # serve the production build locally
```

## Stack

React + TypeScript + Vite + Tailwind CSS. No backend, no database, no
external API calls — everything (market, agent, portfolio) runs
client-side so the app works fully offline once loaded.
